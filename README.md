# Twilight Aurora

Twilight Aurora is a wrapper crate for the twilight crate providing convenient utilities for bot development.

It is primarily designed for use by bots such as [WriterStats](https://writerstats.com/), [Writer-Bot](https://writerbot.xyz)
and [Honeypot](https://honeypotbot.com), and doesn't currently have extensive documentation. This is likely to change in the future, as the crate
grows more mature.
